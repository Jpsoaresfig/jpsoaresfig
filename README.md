## 👨‍💻 About Me

I'm **João Pedro Soares de Figueiredo**, a Brazilian **Full Stack Software Engineer** with 3+ years of experience building web applications, mobile apps, backend systems, and process automation solutions.

Born in Natal, educated in João Pessoa, Brazil, and currently based in **Granada, Spain** 🇪🇸, where I'm pursuing a Master's in Business Process Management and Technologies at the Universidad de Granada.

I enjoy solving real-world problems through software engineering, from designing backend architectures and REST APIs to building user interfaces, integrating AI, and automating business processes.

I've contributed to projects in the **financial, public-sector, and education industries**, with a focus on maintainable code, practical business impact, system integration, and performance.

- 🔭 **Focus:** Full-stack development, backend engineering, AI integration, and automation.
- 💻 **Core stack:** Java, Spring Boot, TypeScript, React, Node.js, Python, and SQL.
- 🤖 **Interests:** AI-powered applications, business process optimization, and scalable systems.
- 🎓 **Education:** B.Sc. in Computer Science and Master's studies at Universidad de Granada.
- 🌍 **Languages:** Portuguese (native), English (C1 written / B2 spoken), Spanish (B2 comprehension / B1 speaking and writing).
- 🚀 **Currently:** Open to software engineering opportunities and impactful projects.

## 📚 Other Technical Projects

### ⚡ Spring Boot vs. Quarkus

**Repository:** [TCC-Jv-Jp-Luiz](https://github.com/TCC-Jv-Jp-Luiz)

A comparative study of Java backend frameworks using equivalent APIs deployed on Kubernetes (GKE) and load-tested with JMeter.

- Compared runtime resource consumption and application performance.
- Measured approximately 271 MiB of idle memory usage for the Spring Boot implementation versus 21 MiB for Quarkus Native in the tested environment.
- Explored deployment, performance testing, and cloud-native backend architecture.

### 📄 APEX Print Server (BIRT)

**Repository:** [apex-print-server-birt](https://github.com/Jpsoaresfig/apex-print-server-birt)

A Java-based reporting service integrating BIRT with Oracle APEX to generate PDF, HTML, and Excel reports.

- Java and Maven.
- Docker-based packaging.
- Reporting and enterprise-system integration.
